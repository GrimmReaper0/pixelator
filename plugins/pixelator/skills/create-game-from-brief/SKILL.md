# Create Game From Brief

1. Read `AGENTS.md`, the active project, and scene summaries through Pixelator MCP.
2. Define player fantasy, primary verbs, loss state, win state, session length, camera, and UI surfaces.
3. Produce a small reviewable plan. Do not begin with a large asset batch.
4. Create a checkpoint.
5. Build one complete playable loop using placeholders and guarded scene patches.
6. Verify boot, input, objective, loss/reset, and runtime errors in the studio preview.
7. Queue only the Anima Turbo candidates needed for the proven loop. Reuse one character visual profile and bounded seed bank.
8. Keep generated candidates unapproved until the user selects them.
9. Replace placeholders without changing stable object IDs.
10. Run validation, tests, and build checks. Report limitations honestly.
