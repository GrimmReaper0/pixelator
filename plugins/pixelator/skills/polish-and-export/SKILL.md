# Polish And Export

1. Confirm required visual assets are explicitly approved and have provenance.
2. Remove player-build debug overlays while preserving editor toggles.
3. Verify HUD readability, responsive behavior, pause/input boundaries, audio controls, and reduced motion.
4. Run project validation, type checking, tests, and production build.
5. Play the complete loop from first actionable screen through win or loss and reset.
6. Confirm export runs without Codex, MCP, ComfyUI, or the studio.
7. Report build path, controls, limitations, and asset-license notes.
